⚖ LEGAL DESK PRO

منصة مكتب قانوني عربية تعمل بالكامل داخل المتصفح — بيانات مشفّرة على جهازك، بلا خادم وبلا اشتراك سحابي.

An Arabic-first, offline legal practice manager in a single HTML file. Everything is encrypted client-side (AES-256-GCM); no server, no tracking.

المزايا
🔐 تشفير كامل للقاعدة بـ AES-256-GCM (مفتاح مشتق بـ PBKDF2)، وقفل تلقائي بعد ١٠ دقائق خمول
📅 تقويم الجلسات مع تأجيل مُتتبَّع وتنبيهات التأخير
🧮 حاسبة المواعيد القانونية (استئناف، نقض، دعوى إلغاء…) مع ترحيل الميعاد لأول يوم عمل
💓 مؤشر صحة القضية من ٠ إلى ١٠٠ مع أسباب الانخفاض
💰 المالية: اتفاقات الأتعاب، الدفعات، المصروفات القضائية، المتأخرات، رسم التحصيل، وفاتورة مطبوعة بترويسة المكتب
⚖️ فحص تعارض المصالح عند إضافة موكل أو خصم
📝 مولّد مستندات (صحيفة دعوى، إنذار، مذكرة دفاع، عقد أتعاب)
🔍 بحث شامل بـ Ctrl+K، ووضع ليلي، وتصميم متجاوب للموبايل
💾 نسخ احتياطي مشفّر واستيراد بدمج بلا حذف
التشغيل

افتح index.html في المتصفح، أو انشره على أي استضافة ثابتة (Cloudflare Pages / Netlify / GitHub Pages). يلزم HTTPS لعمل التشفير.

البيانات تُحفظ في localStorage للنطاق نفسه. فقدان كلمة المرور يعني فقدان البيانات، وحذف بيانات المتصفح يمسحها؛ فاحتفظ بنسخة احتياطية مشفّرة دائمًا.

الترخيص التجاري

النسخة التجريبية مجانية بحد ١٠ قضايا. التفعيل يتم بمفتاح موقّع (ECDSA P-256) يُلصق في تبويب النظام ← الترخيص، ويُتحقق منه داخل المتصفح دون اتصال.

تنبيه قانوني

الأداة تنظيمية ولا تغني عن مراجعة المحامي. مواعيد الطعن والقوالب إرشادية، ويجب التحقق من النص القانوني والعطلات الرسمية قبل الاعتماد.
